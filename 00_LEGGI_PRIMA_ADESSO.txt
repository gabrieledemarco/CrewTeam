🎯 COSA FARE SUBITO (4 PASSI)
═════════════════════════════════════════════════════════════════════════════

PASSO 1️⃣  SCARICA PYTHON
   Doppio click su: SCARICA_PYTHON.bat
   (Apre il browser al download automaticamente)

   ⚪ Se non si apre il browser:
      Visita manualmente: https://www.python.org/downloads/

PASSO 2️⃣  SCARICA IL FILE
   Dalla pagina python.org:
   • Scorri fino a "Python 3.12.x"
   • Clicca: "Windows installer (64-bit)"
   • Il file si scarica in Download/

PASSO 3️⃣  INSTALLA PYTHON
   Doppio click su: python-3.12.x-amd64.exe
   Quando vedi "Add Python 3.12 to PATH":
   ⭐⭐⭐ SPUNTA LA CASELLA ⭐⭐⭐
   Clicca: "Install Now"
   Attendi il completamento

PASSO 4️⃣  RIAVVIA COMPUTER
   ⚠️ IMPORTANTE: Riavvia il computer
   (Serve per aggiornare le variabili di sistema)

═════════════════════════════════════════════════════════════════════════════

2. Digita: py -3.12 --version
3. Dovresti vedere: Python 3.12.x ✅
